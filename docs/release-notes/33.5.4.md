## v33.5.4 — 2026-10-04

v33.5.4 fixes the doc-tools PDF builder for any document that has a bibliography. When `build-pdf.sh` found a `references.bib` beside the document, it stored the two pandoc flags `--citeproc` and `--bibliography=references.bib` in a single string and added that string to pandoc's arguments as one item. Pandoc saw one option it did not recognise and stopped with exit code 6, so every bibliography-backed PDF failed to build. Documents without a bibliography were unaffected, which is why the fault went unnoticed. The flags are now kept as separate arguments, the same way the skill's example script already handled them.

### Fixed

- **Bibliography flags reach pandoc as two arguments** (`0ad29973`, `build-pdf.sh`): the bibliography option is an array whose elements are appended individually instead of one quoted string.

### Verified

- A document from vjspc/netstrata, which carries a `references.bib` and a Chicago CSL style, builds to a 35 KB PDF with the fixed script; the unfixed script stops with "Unknown option --citeproc --bibliography".
- shellcheck reports no warnings.
