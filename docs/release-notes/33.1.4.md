## v33.1.4 — 2026-10-02

v33.1.4 is a housekeeping release that finishes two cleanups. First, the 28 itp-hooks docs spokes and the floating-clock hub stop reading as iteration diaries and state current facts instead. Checking every kept fact against the code turned up about 25 statements that were simply wrong, such as an escape hatch that does not exist and theme, market and profile counts that were years stale. Second, the last 20 files with names over 60 characters are renamed, which completes the naming cleanup begun in v33.1.1 and v33.1.2. The test suites ran the same tests with the same results before and after. Also included: the Stop audit now quotes the current Claude Code docs, plus two fixes from other sessions, for statusline-tools and chrome-profiles.

### Changed

- **itp-hooks spokes and floating-clock CLAUDE.md** (#209, #210): iteration narrative is replaced with current-state facts. Narrative `iter-N` mentions go from 108 to 0 in the spokes and from 15 to 0 in floating-clock. Net, the docs are 143 lines shorter.
- **The last 20 long file names** (#211, #212): each is now at most 57 characters, and every reference is updated. The renames include:
  - the escape-hatch marker registries (`escape-hatch-marker-registry-iter111.ts`, `audit-task-marker-registry-iter114.ts`);
  - four `hooks/lib` modules, each with its paired test;
  - the AskUserQuestion guard (`pretooluse-askuserquestion-line-terminator-guard.ts`);
  - three plugin hook tests.

  ADR filenames are unchanged.

- **Orchestrator test name** (#207, #208): `pretooluse-write-edit-orchestrator.test.ts` now pairs with its module.

### Fixed

- **Doc statements that contradicted the code** (#210):
  - The memory-efficiency spoke documented a nonexistent `MEMORY-EFFICIENCY-OK` escape hatch.
  - The biome spoke listed `useNodejsImportProtocol` as a catch, although the hook skips it.
  - Plan mode is honoured by six hooks, not two.
  - floating-clock has 30 themes, 15 market entries and 8 profiles.
  - The ty Stop check respects the repo's Python pin.
- **Stop audit diagnostics** (#208): the SessionEnd and Notification messages now quote the hooks reference ("Exit code and stderr are ignored"; "Claude Code discards their JSON output fields"). What the audit detects is unchanged.
- **statusline-tools** (365fb17d): the repo version now shows on Linux and with non-origin remotes.
- **chrome-profiles** (1577788c): the throwaway Playwright server is now headless, isolated and named.
