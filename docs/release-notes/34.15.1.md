## [34.15.1](https://github.com/terrylica/cc-skills/compare/v34.15.0...v34.15.1) (2026-11-15)

This patch release makes every cc-skills hook run when its plugin is installed under a path that contains a space. Claude Code replaces `${CLAUDE_PLUGIN_ROOT}` in a hook command with the plugin's install path and runs the result through a shell, unquoted. Orca starts Claude sessions with `CLAUDE_CONFIG_DIR` under `~/Library/Application Support/`, and a `claude plugin update` run in such a session records the install path there. Every hook whose command left the root unquoted then fails with `/bin/sh: …/Library/Application: Permission denied` (exit 126). That was measured on another marketplace's hooks on 2026-11-14. No cc-skills plugin had such a path recorded, so nothing here was broken yet; this removes the failure before the next update from an Orca session can cause it. Claude Code's hooks reference asks for exactly this: "In shell form, wrap each placeholder in double quotes."
