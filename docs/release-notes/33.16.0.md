## v33.16.0 — 2026-10-15

v33.16.0 lets FloatingClock's device rail show what an external job's integrity work is doing, and fixes how the rail looks next to its neighbours. The job's status file can now carry two optional fields. `steps` lists the run's pipeline, and the rail draws one small mark per step before the text: green for done, blue for the step running now, red for a failed step, dim for steps still to come. `badge` is a standing seal, such as the result of an integrity check, shown after the summary when the job is at rest, and also mid-run when it signals a problem. The schema stays version 1, so existing status files render exactly as before. The rail's header now reads like the network rail's `NET Wi-Fi en0`: an all-caps heavy heading in violet (a colour none of the neighbouring rails use), a name, and a dim tag. Its text had sat a little above centre. It is now laid out with the same fixed label height as the network and audio rails, so all three share one baseline.

### Added

- **Pipeline steps** (`61886844`, floating-clock): `steps` as `[[name, state], …]` with states `done`, `active`, `fail`, `todo` and `skip`. Each step draws `▰`, or `▱` while still to do, coloured by state; `skip` draws nothing. The marks sit between the spinner and the phase text, and only while the job's process is alive.
- **Integrity seal** (`61886844`, floating-clock): `badge` and `badge_tone` (`ok`, `warn` or `error`). At rest the seal follows the summary in its tone's colour. During a run it appears only when its tone is not `ok`, so a failure never hides behind the progress line.
- **Header keys** (`61886844`, floating-clock): `DeviceRailName` (the device's name, in lavender) and `DeviceRailTag` (a dim tag) follow the `DeviceRailLabel` heading, which is now heavy and violet.
- **Tests** (`61886844`, floating-clock): a fixture covers step parsing, mark roles, skipped steps, the seal at rest and mid-run, and the header roles. 144 tests pass.

### Fixed

- **Vertical centring** (`61886844`, floating-clock): the device rail used a 16 pt text field placed 2 pt up. NSTextField centres glyphs using metrics that include leading, so the text sat above centre. It now uses the 14 pt centred label height that the network and audio rails use.

### Documentation

- **Overlay indicators** (`61886844`, floating-clock): the two new status fields, the header keys and the shared baseline rule.
