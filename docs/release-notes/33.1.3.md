## v33.1.3 — 2026-10-01

v33.1.3 retires the Ralph-Wiggum lineage. Ralph kept Claude working by having a Stop hook re-prompt it until a task looked done. Claude Code now does this natively: `/goal` keeps working across turns until a condition is met, `/loop` repeats or self-paces a prompt, and long sessions also run well with no harness at all. The plugins that carried the pattern were removed earlier this year (`ru` in April, `autoloop` in June), but their design records and a handful of live mentions remained. This release deletes those records and strips the live mentions. No plugin, hook or skill changes behaviour.

### Removed

- **Ralph and autonomous-loop design records** (#205, #206), which remain in version history:
  - the five Ralph ADRs: eternal loop, dual time tracking, stop visibility, constraint scanning, guidance freshness;
  - the autonomous-loop ADR and the `ru`-removal ADR;
  - the three design specs that paired with them.
- **Live Ralph mentions** (#206):
  - the "Ralph Wiggum" example rows in the hooks lifecycle reference;
  - Ralph-ADR citations in three worktree-manager scripts;
  - a `ralph@cc-skills` cleanup step in `tasks/release/sync`;
  - the TypeScript drift guard's exclusion for `ralph-reference-repos`;
  - "autonomous-loop primitives" in the README tagline.

### Changed

- **ADR coverage figure** (#206): `docs/CLAUDE.md` and `docs/design/CLAUDE.md` now say 30 of 52 ADRs have a design spec, which the doc-count gate checks against the filesystem.
- **The 2026-06-23 removal ADR** (#206): it also records the chronicle-share removal, so it is kept, and its links to the deleted files are now plain text.

### Kept on purpose

- The version guard still exempts `LOOP_CONTRACT*.md` files, because that `/loop` contract pattern is in active use elsewhere.

### Outside the repo

- On the maintainer's machine, the already-disabled `ralph-loop` and `ralph-wiggum` plugins and the `ralph-orchestrator` uv tool were uninstalled, and about 1.2 GB of dead Ralph state and reference clones was deleted.
