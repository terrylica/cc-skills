## Narrative

This release makes the Braille Tally lighter to use in AskUserQuestion. Every option still has to start with its tally, in rank order, but the question no longer needs a legend line in front of it: a question's options always use the default axes, Importance · Urgency · Simplicity, so the legend there was only a preamble the reader had to skip. Lists keep their legend once at the head.

## Fixed

- **No legend preamble in AskUserQuestion:** the guard no longer requires the words "Braille Tally" in the question text; the tally on every option and the rank order stay enforced (#118).
- **Deny message:** says the axes are always the default three and that no legend goes in the question (#118).
- **Tests:** a tallied, ranked question without a legend passes (#118).
- **Docs aligned:** the skill (with an evolution-log entry), README, CLAUDE.md, the hook description, the ADR and the design spec (#118).
