## v32.7.0 — 2026-10-01

v32.7.0 closes a blind spot in the Markdown hard-wrap reminder. The reminder only watched the Write, Edit and MultiEdit tools, so Markdown produced any other way was never checked: a heredoc, `python3 - <<EOF`, a generator script, `sed -i`. On 2026-10-01 a session rewrote dozens of `.md` files through Bash and Python, all hard-wrapped, with the reminder enabled and silent the whole time. This release adds a reminder for Markdown written by Bash commands, and a guard on `git commit`, the one boundary every authoring path crosses. All three surfaces share one net-new detector, so they agree on what a new wrap is. Old wrapped prose still never blocks anything; only wraps a change adds are reported.

### Added

- **`pretooluse-markdown-commit-hard-wrap-guard.ts`** denies a `git commit` that adds hard-wrapped prose to a `.md` or `.markdown` file. It compares what the commit records against `HEAD`, whole file, net-new only. A plain commit reads the index; `-a`/`-am` and `git commit <paths>` read the working tree. It follows `cd dir &&` and `git -C dir`, reads every blob through one `git cat-file --batch` process, and fails open outside a repository or on any git error.
- **`posttooluse-bash-markdown-hard-wrap-reminder.ts`** reminds after a Bash command that wrote wrapped Markdown. It checks the `.md` paths the command names and the Markdown `git status` reports dirty in the repositories it ran in, modified in the last 15 minutes, against `HEAD`. Each file's content is judged once per session, and the edit-time reminder shares that cache, so a wrap is never reported twice. Measured cost: 50–80 ms per Bash call warm.
- **`hooks/lib/markdown-net-new-hard-wraps.ts`**: the shared net-new layer (joiner filter, shape signature, multiset diff, escape marker, repair command, bounded git access).
- 31 tests against real throwaway git repositories, in both directions: wrapped commits denied; clean and legacy-only commits allowed; staged versus working tree; first commit; subdirectory; pathspecs; both escape forms; the dedupe cache.

### Changed

- The edit-time reminder imports the shared layer instead of keeping private copies. Its behaviour is unchanged, and its 44 tests pass as before.
- The `MD-HARD-WRAP-OK` marker covers all three surfaces. As an HTML comment in a file it exempts that file. Anywhere in a commit command, it passes the whole commit. The marker reference, the plugin CLAUDE.md hook tables and the hard-wrap spoke document the new surfaces.
