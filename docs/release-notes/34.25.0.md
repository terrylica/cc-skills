## Narrative

This release adds a forty-second plugin, `staff-onboarding`, and lands six fixes that had waited on review. The plugin gives any organisation one generic way to put a person onto a Google Workspace seat: a single skill, a profile per organisation, and a lessons log that turns into pull requests, so the sign-in traps, mail-copying rules and chat handover no longer have to be relearned in each session. The OCR plugin now produces text on NVIDIA GPUs: the model only returns its transcription when asked in evaluation mode, so every page used to come back as the literal word "None". If that ever regresses, the page now fails with an error naming the cause rather than writing "None". The memory-efficiency card fires only on real data-path code and counts a library only when it is imported. The Telegram CLI tells a new user on a shared Linux host how to set up a profile, including how to sign in to 1Password without the desktop app. The itp-hooks docs index every spoke again and list every subhook, and a new lint fails the gate when either list drifts.

## Added

- **staff-onboarding plugin:** organisation-agnostic Google Workspace onboarding, with one skill, an example profile, profile and lessons contracts, and a contract test (#81, #110).
- **spoke-coverage lint:** `tasks/hook-lint/spoke-coverage.sh` fails when an itp-hooks doc is missing from the spoke index, or when an orchestrator registry entry has no row in its spoke (#138, #136).

## Fixed

- **unlimited-ocr on CUDA:** `model.infer()` is called with `eval_mode=True`, the only mode in which upstream returns text (#116, #115). Contributed by the author of #116.
- **unlimited-ocr, a missing result:** a `None` from the model raises an error naming `eval_mode`, so the batch parser records a failed file instead of a page reading "None" (#130, #129).
- **memory-efficiency and SSoT reminders:** they fire only when the edited file shows evidence, and the evidence check stays linear on long runs of blank lines (#104, #111).
- **memory card evidence:** a library counts only in an import, not when its name appears in a comment or string. `scipy`, `sklearn`, `@tensorflow/tfjs`, Go and Rust CSV readers, and the `.mts`, `.cts`, `.mjs`, `.cjs` and `.jsx` extensions are now covered (#132, #131).
- **tlg on a fresh account:** the unknown-profile error names the profile file and the ways around it. The setup skill covers Linux hosts: a service-account token or a manual `op signin`, one profile and one session per person (#123, #124).

## Changed

- **itp-hooks docs:** three guard spokes are indexed, the PostToolUse orchestrator table lists all its subhooks, and hand-kept guard counts are gone from prose (#138, #136).
- **Removed:** the Telethon-era `plugins/tlg/docs/history.md`. The statusline manual lychee test prompt is linked from its plugin hub instead of from nowhere (#138, #136).
