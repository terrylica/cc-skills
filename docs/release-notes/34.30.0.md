## Narrative

This release gives web-forge a second Gmail routing recipe. The existing `gmail-default-routing` recipe drives Gmail's Default routing, which only ever sees mail addressed to the organisation's own domain, so it cannot redirect mail that users send out. Redirecting outbound mail for one outside address (for example, a retired personal address that people keep picking from their contacts) needs the per-organisational-unit "Routing" setting, and no API writes it: Google's list of settings the Cloud Identity Policy API supports has Gmail "Routing > Manage address lists" but no routing rules. The new `gmail-routing` recipe fills that dialog the same way as its sibling (spec, form operations, read-back before Save, reload, read-back after), and it identifies a rule by the description Google stores, which the Default routing dialog lacks. It was built and proven on a live console, where a review round also hardened it: the rule's Edit dialog is opened by its exact description rather than by its position in the table, and a disabled rule never counts as verified.

## Added

- **web-forge `gmail-routing ensure`:** Admin console › Gmail › Routing › Routing, per organisational unit, inbound or outbound; flags `--description`, `--messages`, `--account-types`, `--envelope-recipient single:<email>`, `--change-envelope-recipient`, `--add-original-to-header`, `--org-unit`, `--dry-run`, `--verify`, `--update`.
- **Safe identity:** the Edit dialog is opened by the row's exact Description cell, and a found rule counts only when its dialog shows the spec's description and its row reads Enabled; otherwise the run exits 1 as `row-mismatch` or `disabled` and changes nothing.
- **No half-saved rules:** a filled form that does not read back as the spec is cancelled and reported as `fill-mismatch`, with the raw form for debugging.
- **Unit tests** built from a form captured on the live console and anonymised to example.com, including the two "Email address:" fields (senders' first and hidden, recipients' last).

## Changed

- **admin-console skill:** a section for the new recipe, its measured page structure ("Show options" is a link; each setting is a form named after it), and a re-authentication lesson: when a password manager's frame on Google's "verify it's you" page detaches the Playwright extension, pass the check in the profile's own window, then re-run.
