## v33.5.3 — 2026-10-04

v33.5.3 is a documentation release that finishes moving the gh-tools plugin's examples to the operator's current folder layout. The plugin's guidance on when it is safe to post an issue comment still used the retired folders `~/vj` and `~/own` as its examples of mapped paths, and `~/vj/collab` as a collaborator prefix. Those folders no longer exist, so a reader could take them as live rules. The examples now show `~/eon` and `~/gh/<org>`. The fine-grained PAT skill's lessons also cited the `vanjobbers` account, which since the 2026-10-03 renames is a different account from the one those lessons were measured on; they now say so.

### Changed

- **gh-tools path-owner examples** (`8baf30d2`): the mapped-path example reads `~/eon` → `terrylica`, `~/gh/<org>` → `<org>`, and the collaborator example keeps only `~/eon/collab`.
- **gh-fine-grained-pat lessons** (`8baf30d2`): the passkey-session and sudo-race lessons note that the account they name is today's `cptbc`.

### Verified

- No code changed; the plugin validator runs as part of the release gate.
