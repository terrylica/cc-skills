## v33.1.0 — 2026-10-01

v33.1.0 is a housekeeping release. Its one new capability is that the 16 hook-lint audits now run on every push. Until now, 14 of them ran only in the release preflight, so a broken hooks.json or hook source reached main and was found only at release time. They now live in `tasks/hook-lint/` under short names, behind a single runner that `repo:check` depends on, at about 1 s of wall time. The rest of the release removes dead code and stale documentation, and fixes the cause of two intermittent gate failures. Three unregistered guards and an audit nobody ran are deleted. Three bash marker-lookup scripts collapse into one TypeScript CLI, which also closes a query-injection bug. The CLAUDE.md hubs drop dated narratives and stale counts. The commits doctor and the test runners stop running the developer's global git hooks inside throwaway fixture repos, which made both fail intermittently under load.

### Added

- **`repo:hook-lint` in the push gate** (#189, #190): `tasks/hook-lint/run` runs every `tasks/hook-lint/*.sh`.
  - At most 4 run at once.
  - Each prints PASS or FAIL with elapsed ms, plus the last 30 log lines for each failure.
  - The directory listing is the only list, so adding a lint means adding a file.

### Changed

- **Hook-lint audits renamed and moved** (#190): 16 iteration-numbered `tasks/` scripts, with names of about 150–200 characters, become `tasks/hook-lint/<short-name>.sh`.
  - The commit-history audit becomes `tasks/commits/conventional-conformance.sh`.
  - The plugin-cache diagnostic becomes `tasks/diagnose-plugin-cache-drift.sh`.
  - The one-off `audit-orchestrator-spawnsync` moon task is removed, because the runner covers it.
- **Marker lookup is one CLI** (#184): `tasks/marker-lookup.ts [--json] [--direction=forward|reverse|auto] <query>` replaces three bash scripts (1,055 lines become 313).
  - Exit codes: 0 found, 1 not found, 2 usage error.
  - `--json` always returns the `.dispatchedBackendResponse` envelope.
- **CLAUDE.md sweep** (#182):
  - The root, `plugins/` and `docs/` hubs are slimmed.
  - Dated narratives move to `plugins/ssh-tunnel-companion/docs/research-and-roadmap.md` and `plugins/tlg/docs/history.md`.
  - Stale counts are corrected: floating-clock themes and exchanges, tlg skills, and gh-tools gotchas.
  - The devops-tools secrets section now follows the self-custody-first credential ladder.
  - `bash-compatibility.md` is rewritten from a measured zsh probe, and the bash-wrap rule from 2025-12-22 is retired.
- **Doc-count gate** (#182): `verify-doc-counts` drops three rules whose counts no longer appear in the docs. It now checks directly that every plugin has a CLAUDE.md.

### Fixed

- **Commits doctor Check 14** (#117, #178, #187, #188): the throwaway probe repo no longer runs the developer's global git hooks.
  - Template hooks were stopped with `core.hooksPath=/dev/null`.
  - Config-based hooks (git ≥ 2.54) were not, so `hook.<name>.enabled=false` is now set for each one through the shared `tasks/lib/hermetic-fixture-git.sh`.
- **Test runners** (5463d342): the suite runners disable config-based global hooks in their fixtures through the same helper.
- **iter-152 dashboard** (#186): it reads its windows with `awk`, not `head`, so the writer can no longer be killed by SIGPIPE under `pipefail`. Its test now prints the renderer's exit code and output tail when it fails.
- **Marker lookup query injection** (#184): the query is no longer interpolated into code.
- **itp-hooks hub** (#182): a malformed table row is fixed, and the hard-wrap escape token is written split so it no longer silences the hook for that file.

### Removed

- **Unregistered guards** (#180): `pretooluse-fake-data-guard.mjs` and its patterns, `pretooluse-inline-ignore-guard.ts` and `pretooluse-iter78-layer3-stripped-path-edit-time-guard.ts`, with their tests and docs, plus the iter-77 audit. None was registered in hooks.json.
  - The marker registry drops LAYER3.
  - `INLINE-IGNORE-OK` now names its live consumer, `code-correctness-guard.sh`.
  - The fake-data ADR and spec are marked superseded.
- **Retired-plugin leftovers**: plugin-dev references no longer cite the retired TTS plugins as live examples. Tombstone rows for deleted files are dropped.
- **`docs/plugin-authoring.md`** (#182): it duplicated `plugins/CLAUDE.md`.

### Issues closed

- #38 (rust-analyzer SSR refactoring skill) and #54 (gemini-deep-research resilience findings) are closed as not planned.
