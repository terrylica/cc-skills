## v33.7.0 — 2026-10-04

v33.7.0 makes the release and commits tooling say what its settings do, and removes the parts of its documentation that had stopped being true. The 23 environment variables that tune the release pipeline and the commits toolkit were named after the iteration that added them (`ITER134_PREFLIGHT_AUDIT_PARALLEL_LANES`, `ITER152_WORST_OFFENDER_CALLOUT_COUNT`); they now have descriptive names such as `PREFLIGHT_AUDIT_PARALLEL_LANES` and `COMMITS_HEALTH_LONGEST_COUNT`. The old names keep working and print a one-line notice naming their replacement, and they will be removed no earlier than 2027-01-04 in a major release (#226). `docs/RELEASE.md` shrinks from 902 lines to a 270-line reference: the iteration log of measurements and forensic notes is gone (git and the CHANGELOG keep it), and the troubleshooting advice that described hooks being copied into `settings.json`, or recommended a bare `git stash` in a checkout shared by several sessions, is corrected. The release preflight also stops ending its count-reading pipelines with `head -1` under `pipefail`, a race that could turn a count into two lines.

### Added

- **Descriptive names for the 23 operator env knobs** (`5c8bde2c`, closes #224): shell scripts read each one through `cc_knob` in `scripts/lib/env-knob.sh` (new name, else old name with a stderr notice, else default). The copied `commit-msg` hook and the two Python scripts carry the same rule inline. Four knobs that code read but no document listed are now documented. The commits doctor's fork budget caught a first version that forked per read; the shipped helper assigns with `printf -v` and stays at the 27-fork ceiling.

### Fixed

- **Release preflight reads counts with a reader that drains its input** (`01243c09`, #222): 41 `head -1` and one `head -n N` pipelines under `set -euo pipefail` become `awk 'NR==1'` / `awk 'NR<=n'`, so a producer can no longer be killed by SIGPIPE and leave `N` plus `0` in a count variable.
- **The doc-count gate checks plugin counts in any wording** (`cb80b9b1`, #220): a residue check reports a plugin count no rule recognises, and a new rule checks the "N plugins ship one" `plugin.json` claim against the tree.

### Documentation

- **`docs/RELEASE.md` is a reference, not a log** (`593e5b73`, #222): every live knob with its effect and default, the commits toolkit, the semantic-release speed-ups and the rule for reading audit counts. A new test derives the toolkit's task list from `moon.yml` and found `repo:commits-perf-baseline` undocumented.
- **Two drifted plugin counts removed** (`9736b347`): the README's "all 36" (there are 39) and notes-commander's "all 27" (21).
- **SCS tiered Touch-ID ADR amended** (`9690d5bc`): CryptoKit Secure Enclave keys, kept as enclave-wrapped blobs in a file, need no Developer ID; the earlier finding held only for Keychain-persisted keys.

### Verified

- `repo:release-preflight` passes when set through a new knob name with no notice, and through the old name with exactly one deprecation notice.
- `repo:test-hooks`: 115 of 115 test files, including `test-env-knob-aliases.sh` (9 cases) and the fork-budget test (doctor 27 ≤ 27).
