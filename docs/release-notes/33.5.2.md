## v33.5.2 — 2026-10-04

v33.5.2 removes a dead default left by the operator's folder migration. The TypeScript drift guard compares the TypeScript version each repository declares with the one actually installed, and by default it searched `~/eon`, `~/gh` and `~/vj`. The last repositories under `~/vj` moved to `~/gh/ZmBrandon` on 2026-10-04 and the folder was retired, so that third root no longer exists. The guard already skipped a missing root without an error, so its results do not change. This release only takes the retired folder out of the code, the help text and the header comment, so the defaults describe the machine as it is.

### Fixed

- **Drift guard default roots are `~/eon` and `~/gh`** (`0e7a731c`): the retired `~/vj` folder is gone from the default search roots, the `--roots` help text and the file's header comment.

### Verified

- The guard's nine regression tests pass.
- Running it against a root that does not exist still prints "No package.json files found" and exits cleanly, which is why the old default caused no failures.
