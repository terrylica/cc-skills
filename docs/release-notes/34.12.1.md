## [34.12.1](https://github.com/terrylica/cc-skills/compare/v34.12.0...v34.12.1) (2026-11-05)

This patch release fixes two places where a tool reported success while the result was wrong. The disk-hygiene skill used `du` to predict how much space a cleanup would free, and on APFS that number can be far too high. In a real audit, three deletions came to about 64 GB by `du` and freed about 15 GB by `df`, because the deleted files were clones sharing blocks with another store. The skill now names the store that actually holds the blocks for each case and tells the agent to measure with `df` before and after. The gh-tools PAT automation could not sign in again after a session cookie expired: GitHub's /login page asks for a username as well as a password, and the password fallback left it empty.

### Summary

- **devops-tools (disk-hygiene):** per-user Aerial wallpaper videos are APFS clones of the root-owned system store under `com.apple.idleassetsd/Customer`. Deleting the per-user copies frees almost nothing; the system store is the one to clean, and macOS downloads again only the aerial in use.
- **devops-tools (disk-hygiene):** bun installs `node_modules` as clonefile copies of its own cache, so removing agent worktrees frees far less than `du` reports. A worktree locked by a live agent (`git worktree remove` names the pid) stays.
- **devops-tools (disk-hygiene):** some Hugging Face caches are deduplicated into a second, shared `hub/blobs/<xx>/<sha>` store. Delete the blobs that only stale models reference (`realpath` + `comm -23`), then the model dirs; the model dir alone frees nothing.
- **devops-tools (disk-hygiene):** the evolution log records the measured `df` gain of each step, from 106 GB to 197 GB free.
- **gh-tools (gh-fine-grained-pat):** the autonomous sign-in fills the username on GitHub's /login page when the field is empty or holds another account, and passes the account through `autonomousSudo()`. Four unit cases cover the login and sudo pages; recorded as GOTCHA #22.
