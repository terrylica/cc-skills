## [34.8.0](https://github.com/terrylica/cc-skills/compare/v34.7.0...v34.8.0) (2026-10-27)

Driving a signed-in Chrome profile from Claude Code had two remaining sources of human friction and clutter. First, the Playwright Extension server only sees the tabs of its own session, so tabs a run left behind (popups, "View rule" links, an ad-hoc client that never closed its tab) piled up in the operator's Chrome where no automation could see or close them. Second, a profile whose stored extension token was missing or stale made every connection stop on the extension's "… is trying to connect" page until a person clicked "Allow & select", and that page shows the token in plain text. This release closes both: Chrome's own AppleScript dictionary now lists and closes any tab of any profile with no extension, debug port or dialog, every `mcp-drive.ts` run sweeps the tabs it opened, and no route waits on a click any more, because a missing token is refused up front, drift is detected, and a token can be rotated without a person. The browser-MCP reminder hook also moves into the plugin, so every host with chrome-profiles gets it rather than one Mac.

### Summary

- **chrome-profiles:** `chrome-profile.sh tabs list [--json] [--url-match <re>]` and `tabs close --id <tabId>…` (new `scripts/chrome-tabs.ts`): every tab of every profile through JXA; closes only exact ids or a URL match bounded by `--max`, compares ids as strings, refuses to empty a window without `--allow-window-close`, never launches Chrome, and names osascript -600 (outside the desktop session) and -1743 (no Automation grant).
- **chrome-profiles:** `mcp-drive.ts` lists tabs before and after each run and closes those that appeared on a host named in its steps, plus the extension's connect page; `MCP_DRIVE_NO_SWEEP=1` turns it off. Measured: the sweep closed a popup that a control run without it left open.
- **chrome-profiles:** `playwright-mcp` refuses to start without a stored token instead of opening the connect page; `doctor` compares digests of the stored and the extension's current token; `setup` replaces a stale token, closes the status tab it opened, and refuses to re-use a server name that already drives another email.
- **chrome-profiles:** `rotate-token <email>` presses the extension's own "Generate new token" through Accessibility in the one window titled with that email, waits until the new token reaches disk (about 15 s), stores it and closes the page. Measured: a run presenting the rotated-out token was refused.
- **chrome-profiles:** the browser-MCP reminder hook ships in `hooks/hooks.json`; it points agents at the shipped `mcp-drive.ts` and `tabs` instead of a hand-written client, and stays quiet for search and VCS commands that merely mention CDP (12-case regression test, four of which fail against the old hook).
- SKILL.md and doctrine.md record the tab, connect-page and token-rotation mechanics, the paste-then-verify rule for messages, and the keep-out-of-the-automated-window rule.

### Features


* **chrome-profiles:** ship the browser-MCP reminder hook with the plugin ([b7248a8](https://github.com/terrylica/cc-skills/commit/b7248a82b1e043274eeff586507aa149aee6c1f3))

Moved from a private ~/.claude hook, so every host with the plugin gets it. It now points agents at the shipped mcp-drive.ts and chrome-profile.sh tabs instead of telling them to hand-write a JSON-RPC client (the hand-written one leaked tabs), and the PreToolUse check stays quiet for search and VCS commands that merely mention CDP. Regression test: plugins/chrome-profiles/hooks/tests/test-browser-mcp-config-reminder.sh (12 cases; four of them fail against the old hook).

* **chrome-profiles:** tabs list/close for every profile, leftover-tab sweep, no route waits on a click ([f42fd6f](https://github.com/terrylica/cc-skills/commit/f42fd6fc54fbb91452ca541e4d84f96b67ca9433))

- chrome-tabs.ts: list and close any tab of any profile through Chrome's AppleScript (JXA): no extension, no debug port, no Allow dialog. Closes by exact id or a URL match bounded by --max, compares ids as strings, refuses to empty a window without --allow-window-close, never launches Chrome, names osascript -600 (outside the desktop session) and -1743 (no Automation grant).
- chrome-profile.sh tabs: execs chrome-tabs.ts.
- mcp-drive.ts: lists tabs before and after each run and closes the ones that appeared on a host named in its steps, plus the extension's connect page (MCP_DRIVE_NO_SWEEP=1 turns it off).
- playwright-mcp refuses to start without a stored token instead of leaving the extension's "is trying to connect" page waiting for a person.
- doctor compares digests of the stored and the extension's current token; setup replaces a stale token and closes the status tab it opened; setup re-uses the server name already serving an email and refuses a name serving another email (a local-part collision had repointed a server at the wrong account).
- rotate-token &lt;email>: presses the extension's own "Generate new token" through Accessibility in the one window titled with that email, polls until the new token reaches disk, stores it and closes the page.

Measured on macOS: live nonce-tab test (open 2, close by id, tab set restored); sweep closed a popup that the control run (sweep off) left open; a run with a rotated-out token was refused; doctor reported 12 registered profiles, 11 matching and 1 with no token, then fixed.
