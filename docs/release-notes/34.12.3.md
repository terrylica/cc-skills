# 34.12.3 — 2026-11-07

## What this release does

**Tables in full-width Orca artifacts no longer squeeze a column until its words break apart: cells keep whole words, and a small script in each page sizes the columns from their measured content.**

The full-width-artifact template set `overflow-wrap:anywhere` on every table cell. Under automatic table layout a browser gives each column at least its min-content width, and with `anywhere` that minimum is one character, so a short column beside long prose shrank until its header broke into one letter per line. Cells now break only between words, and each page that has a table carries an inline script (Orca's artifact frame allows inline scripts) that measures every cell once and sets the column widths on every resize. It applies LaTeX tabulary's rule first, so a column whose longest cell fits in an equal share stays on one line, then gives the remaining width to whichever column shortens the table most. In a 1300 px headless-Chrome window an eight-column test table kept every header whole and needed about a quarter less height. Pages published before this release keep the old layout until they are re-published.

## Changes

#### Fixed

- `orca-artifact-share`: table cells use `overflow-wrap:break-word`, `word-break:normal` and `text-wrap:pretty`, and headers use `text-wrap:balance`. Only links and code inside cells may break anywhere, so a long URL cannot force a table wide.
- Uploaded HTML gets the same cell rules in its override stylesheet.

#### Added

- `planColumns`, a pure column-width planner that applies the tabulary rule and then minimises the table's estimated height. Each column gets a comfortable minimum of 7 em, which gives way first on a narrow screen. A whole word never breaks; the table scrolls in its own box instead.
- `FIT_SCRIPT` (`<script data-orca-table-fit>`), added once to every generated page with a table and to uploaded HTML that has one. It skips tables with `colspan`/`rowspan`, nested tables, tables whose author set `<col>` widths, and anything inside `[data-fit=off]`. A table hidden at load (a closed tab or `<details>`) is fitted when it appears. In uploaded HTML without a scrolling parent, each table is first wrapped in an `overflow-x:auto` box, so a wide table cannot push the page sideways.
- Six tests covering the cell CSS, the planner (one-line fit, a label column beside prose, the bottleneck column, floors) and idempotent injection.

#### Changed

- `SKILL.md` gains a "Tables: columns are fitted, never squeezed" section with the measured cause and method, and a reflection step for lopsided tables.
