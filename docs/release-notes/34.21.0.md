## Narrative

This release is mostly about things that kept breaking quietly. Plugin CLIs that need npm packages (Telegram, Gmail, Google Drive, Pushover rendering) failed after every plugin update, because Claude Code installs a plugin's packages only from a `package.json` and lockfile at the plugin root, and ours sat in sub-folders. Instead of a session-start hook that installs on every machine, the three pure-JavaScript CLIs now ship their one third-party package as a committed, reviewable bundle (0.3 to 1.3 MB against 42 to 59 MB of `node_modules`), and Pushover, whose renderer is a native addon that cannot be bundled, moved its packages to the plugin root where Claude Code's own install covers it. The pre-push gate also stops failing under machine load: three tests that assumed fast process start-up or a toolchain that never changes mid-run now wait on events with bounded ceilings, and say why when they fail. A new reminder points agents at the lightest headless browser that can do a job, and Chrome no longer collects a saved "Playwright" tab group on every automated run. Alongside these, superseded ADRs, unreferenced scripts and dated CLAUDE.md narrative were removed after reference checks.

## Added

- **Vendored plugin packages:** `scripts/vendor-plugin-deps.ts` bundles the exact runtime exports a CLI uses from its committed `bun.lock`, with type re-exports and the license text of every bundled package; `moon run repo:vendor-deps-check` (in `repo:check`) compares a recorded inputs hash, so a Bun upgrade alone never fails the gate (#91, #113).
- **Headless browser tier reminder:** a soft PreToolUse reminder when a command starts a heavy browser for work that needs no window, classified per real shell invocation; it never auto-approves an MCP call (#69, #63).
- **Saved tab-group count:** `chrome-profile.sh saved-groups <email>` and a `doctor` line report leftover saved Playwright groups, counted from the profile's sync store (#82).

## Fixed

- **CLIs survive plugin updates:** tlg, gmail-cli and gdrive run with nothing installed (verified from fresh copies with Bun's auto-install off); pushover's packages install at its plugin root (#91, #113).
- **Gate flakes under load:** the review-round gate's lookup budgets are raised for tests only, `compute_metrics` waits out a mid-run `uv` install and skips only for that, and `orca-closeout` tests poll instead of racing fixed deadlines and report stderr on failure (#83, #114).
- **No saved tab group per run:** the Playwright MCP launcher passes `--no-tab-group` (upstream microsoft/playwright#43814) (#82).
- **Admin-console 2SV lessons:** the review fixes that missed PR #61's merge landed (#112).

## Removed

- Four superseded ADRs and three design specs whose subject code is gone, nine unreferenced scripts and fixtures, a dead Objective-C function, and dated narrative or duplicated rules in eight plugin CLAUDE.md files; every rule kept inline or linked (#72, #73).
