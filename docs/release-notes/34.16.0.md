## [34.16.0](https://github.com/terrylica/cc-skills/compare/v34.15.1...v34.16.0) (2026-11-15)

This minor release makes every Cloudflare Workers or Pages deploy leave a trace that cannot be forgotten. The operator keeps one sitemap of every published Workers link, with its provenance, and wants it current on both machines without relying on memory. itp-hooks now notices each deploy command an agent runs and records it under `~/.local/state/cf-sitemap/`. It reminds the agent to update the sitemap, and holds the end of the turn until the sitemap is newer than the deploy. The hook knows nothing about accounts, hosts or URLs: each machine names its own update command in `~/.config/cf-sitemap/hook.json`, so this public repository carries only the mechanism. A session is held at most three times per deploy and never for another session's deploy, so a sitemap that cannot be updated at that moment never traps work.

### Summary

- **itp-hooks, PostToolUse (Bash):** `posttooluse-cloudflare-deploy-sitemap-reminder.ts` ([#88](https://github.com/terrylica/cc-skills/pull/88)).
  - **What it notices:** `wrangler deploy`, `wrangler pages deploy`, `wrangler versions deploy` and a repository's `workers_deploy.sh`. Dry runs, `--help` and the sitemap tool's own deploys are skipped.
  - **What it does:** records the deploy with the session id and prints the machine's update command.
- **itp-hooks, Stop:** a fifth subhook in `stop-orchestrator.ts`, `stop-cloudflare-sitemap-pending.ts`.
  - **What it blocks:** the end of a turn while that session's deploy is newer than `last-sitemap.json`.
  - **Loop guards:** it reads `stop_hook_active` and blocks at most three times per deploy.
- **Remote updates:** when a machine updates the sitemap on another machine, it runs the printed `mark` command afterwards so its own state shows the update.
- **Escape hatch:** `CF-SITEMAP-OK` in a command, for a deploy that publishes no link.
- **Tests:** `hooks/cloudflare-deploy-sitemap.test.ts` (16 cases) covers deploy and non-deploy commands, recording, the escape hatch, session scoping, the block cap, a newer sitemap and the mark command.
