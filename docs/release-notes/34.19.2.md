## [34.19.2](https://github.com/terrylica/cc-skills/compare/v34.19.1...v34.19.2) (2026-11-16)

This patch repairs web-forge's GitHub OAuth-app forge after GitHub changed its "New OAuth App" form. On 2026-11-16 the single "Authorization callback URL" field, `oauth_application[callback_url]`, became a "Redirect URI" list with one row per URI, and `gh-oauth-app.mjs` filled the callback by that exact name, so it could no longer fill the form. A read-only probe of the signed-in form (control names, ids and labels only; nothing created) gave the new shape. The forge now finds each field by its visible label first and by a name pattern that tolerates a rename second, refuses to guess when a rule matches several fields, and reads every value back before it presses Register.

### Bug Fixes

- **web-forge, `cf-access-wall/scripts/gh-oauth-app.mjs`**: fills the application name, homepage and callback through the new field finder instead of three exact `name` selectors. The callback lands in row 0 of the Redirect URI list, `oauth_application[application_callback_urls_attributes][0][url]`, never in its hidden `_destroy` input or its "Allow wildcard matching" checkbox.
- **New `cf-access-wall/scripts/oauth-form.mjs`** (pure, no Playwright import): `readControls` runs in the page and lists every `oauth_application[…]` control with its label; `pickField` matches label then name and throws on zero or several matches with the fields it saw; `selectorFor` builds an id or exact-name selector with quotes escaped.
- **Read-back before submit:** a field that holds anything other than the value just filled stops the run before Register, so a half-matched form never creates a broken app.
- **Verified on the live form:** `readControls` and `pickField` were run against the signed-in "New OAuth App" page and picked `[name]`, `[url]` and the row-0 Redirect URI, each by its label.
- **Tests:** `oauth-form.test.ts`, 7 tests over the form as it was until 2026-11 and as read on 2026-11-16: label matches on both shapes, the name-pattern fallback when a label changes, refusal on two Redirect URI rows, the error that names where to fix a further change, fillable types and selector escaping.
- **Docs:** a dated drift note in dashboard-forge's Vendor Quirks records the new form's controls (name, homepage, description, Redirect URI rows, Device Flow, token expiration); the 2026-07-23 entry points to it; web-forge's `CLAUDE.md` names the field finder.
