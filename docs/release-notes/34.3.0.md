## [34.3.0](https://github.com/terrylica/cc-skills/compare/v34.2.2...v34.3.0) (2026-10-22)

This release lets you choose what the statusline-tools status line shows. Until now its layout was fixed: every machine that used it got the code statistics line, the clock, and, where a gateway was configured, the gateway health. That is too much for a machine set up for somebody else, who should see their own session and repository and nothing about the infrastructure behind it. A new setting, `STATUSLINE_HIDE`, takes a comma-separated list of segment names and leaves those out. Hidden segments also stop costing anything: hiding the code statistics skips running scc, and hiding the gateway switches that whole feature off, so no probe is sent and no cache or telemetry file is written. With the setting unset, the status line renders exactly as before. The release also carries a privacy fix: a test fixture that used a real host name now uses a generic one, and one older CHANGELOG entry no longer links an issue in a private repository.

### Summary

- **statusline-tools:** `STATUSLINE_HIDE` accepts `git`, `code`, `model`, `ctx`, `datetime`, `gateway`, `repo`, `session`, `cast` and `cron`, for example `{"env": {"STATUSLINE_HIDE": "code,datetime,gateway"}}` in `~/.claude/settings.json`.
- **statusline-tools:** hiding `code` skips scc entirely, and hiding `gateway` sets the gateway feature to unconfigured: no outbound probe, no floor cache, no `gateway-state.jsonl` append.
- **statusline-tools:** the datetime line is dropped only when both `datetime` and `gateway` are hidden; hiding just `datetime` leaves the gateway health on its own line.
- **statusline-tools:** unknown names and stray spaces are ignored, so a typo can never break the render; an unset value is byte-for-byte the old output.
- **statusline-tools:** five new bats tests pin the behaviour (named lines dropped, datetime line dropped, no gateway side effects, scc not run, unknown names inert); the suite is 44/44.
- **statusline-tools:** the README's layout section, which still described five lines, now lists every line in order with its name and an example.
- **privacy:** the long-runtime monitor reminder test's fixture host is now `remote-host`, and a v33 CHANGELOG link to a private repository's issue is reworded, so the tip tree carries no identifiers the privacy gate blocks.
