## [34.13.3](https://github.com/terrylica/cc-skills/compare/v34.13.2...v34.13.3) (2026-11-12)

When an itp-hooks guard blocks a command it names the document that holds the rule. For the release-notes, TypeScript 7 and WebFetch rules that document had been a three-line redirect since 2026-09-23, when the three doctrines moved into skills, so a blocked user was sent to a pointer instead of the rule, and the redirects could not be deleted while this repository named them. This release makes every live pointer name the skill file itself. No guard's behaviour changes: what is blocked and what is allowed is the same as in 34.13.2, and only the path in messages, comments, tests and docs differs.

### Summary

- **Hook messages:** the TypeScript version guard, the legacy-install guard, the TypeScript upgrade reminder, the release-notes extensiveness guard and the WebFetch fallback guard now print `~/.claude/skills/typescript-7/references/doctrine.md`, `~/.claude/skills/release-notes/references/doctrine.md` and `~/.claude/skills/web-fetch/SKILL.md` ([#76](https://github.com/terrylica/cc-skills/pull/76), closes [#75](https://github.com/terrylica/cc-skills/issues/75)).
- **Scope:** 25 files changed their pointer (hooks, the escape-hatch registry and its reference, the bootstrap-monorepo skill and its `tsconfig.base.json` template, the release scripts). The two design records dated 2026-07-21 keep the old path as history.
- **Two small corrections found on the way:** a doubled `~/` in the hard-wrap guard's header comment, and the TypeScript version guard's section pointer, which named a heading the doctrine does not have ("Enforcement") and now names the one that holds the text ("Staying current").
- **docs/RELEASE.md:** reflowed with `gfm-unwrap.ts` (35 joins) because the commit guard refuses hard wraps on touched lines; a word-level diff shows the pointer as the only wording change.
- **Tests:** one assertion follows the new path; the 11 test files of the touched hooks pass (326 tests, 0 failures).
- **Also in this range:** a documentation commit, "docs(scs): verified recipe for agent web sign-in from a vault item" ([#77](https://github.com/terrylica/cc-skills/pull/77)), which semantic-release does not list.
- **For other machines:** these paths exist only where the operator's private `~/.claude` skills are present, as was true of the redirects they replace.
