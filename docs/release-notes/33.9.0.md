## v33.9.0 — 2026-10-07

v33.9.0 is the first release after this repository was deleted and recreated with its history rewritten, and it adds one skill. The new `gmail-commander:mailbox-consolidation` skill records, without any project detail, what it takes to fold several legacy addresses (consumer Gmail accounts and mailboxes in other Google Workspace tenants) into one shared Workspace inbox. Each source type needs a different mechanism, and each fails silently in its own way. The skill covers the routing-rule default "Do not deliver spam to this recipient", which drops copies without a bounce. It also explains why to switch forwarding on before the final history copy, and how to find and close remaining gaps exactly, by Message-ID. The rewrite changed every commit ID from August on, so this release also translates 3,681 references in the tree (CHANGELOG links, release-note documents, code comments, and a test that runs `git show` on a historical commit) to their new IDs. Without that, those links would point at nothing and the test would fail. Anyone with an older clone needs to clone again: the old commit IDs no longer exist here.

### Added

- **`mailbox-consolidation` skill** (`72b30602`, gmail-commander): survey each mailbox's live forwarding state through the API, pick the mechanism per source (consumer Gmail has no forwarding API; another tenant's mailbox uses an Admin-console routing rule), keep spam checks from swallowing copies, and prove each path end to end with Email Log Search and the Reports API.
- **Closing gaps by Message-ID** (`5862c5ef`, gmail-commander): list the hub's Message-IDs, list each source's inbound mail, copy exactly the missing messages with `messages.insert` (`internalDateSource=dateHeader`), then re-run until it reports zero missing. This needs no new consent, works across tenants, and a re-run never copies twice.

### Fixed

- **Commit references after the history rewrite** (`4bf2dfd0`): 3,681 references in 32 files now use post-rewrite IDs, translated through the git-filter-repo commit map at the same length. Only IDs changed; no prose was edited.
- **Skill structure** (`ea627e1d`, gmail-commander): the new skill ends with the Post-Execution Reflection section that the self-evolution check requires.

### Documentation
