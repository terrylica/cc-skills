## [34.5.0](https://github.com/terrylica/cc-skills/compare/v34.4.0...v34.5.0) (2026-10-24)

This release gives AI coding agents under the Orca IDE one place to run a command that needs a person: Orca's own floating terminal. An agent's Bash tool has no terminal anyone can see or answer, so biometric unlock, a password manager's desktop-app integration, `sudo`, passkeys and interactive prompts either fail there or get handed back to the person as a command to paste. The new orca-tools `floating-terminal` skill runs such a command in the floating terminal, which exists on every Orca desktop, using nothing but Orca's CLI. It waits while the person answers and hands back the command's real exit code and the last lines of its output as JSON. It does not trust Orca's own exit report, because `orca terminal wait` was measured reporting exit 0 for a command that exited 7. Instead the command runs under `script`, a real TTY, and writes its own status file. The repository's root guidance now makes this the default for agents under Orca, on macOS and Linux, in place of opening iTerm, Terminal.app or gnome-terminal.

### Summary

- **orca-tools:** new `floating-terminal` skill with `orca-float run -- CMD`, `open` (an interactive floating shell) and `doctor` (creates and closes a probe tab and confirms it landed in the floating terminal).
- **orca-tools:** the JSON reply is `{ok, state, exit_code, handle, tab_closed, seconds, output}`. `state` is `finished`, `timeout` or `gone`; exit 0 ok, 1 failed or unfinished, 2 usage, 3 no Orca CLI.
- **orca-tools:** a successful run closes only its own tab, by handle and never with `--all`. A failed run keeps its tab so the person can read it; `--keep` keeps it anyway.
- **orca-tools:** `--no-log` for commands that print a secret. The temporary run directory is mode 700 and removed after every run.
- **orca-tools:** a shared Orca CLI finder, `scripts/lib/orca-cli.sh`. It never trusts a bare `orca`, which on Linux desktops is often the GNOME screen reader.
- **docs:** the root CLAUDE.md states the rule and adds a "Human-in-the-loop command" row to the reuse registry. The plugin CLAUDE.md, README and marketplace entry list the skill, and the plugin CLAUDE.md records what was verified.
- 12 Bun tests run against a stub Orca CLI, and the live macOS runs are recorded. Linux has not been run live yet.
