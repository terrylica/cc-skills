## [34.18.0](https://github.com/terrylica/cc-skills/compare/v34.17.2...v34.18.0) (2026-11-15)

This release adds one standard for every HTML page an agent publishes, and a reminder that points at it. Pages were going out without a dependable answer to three questions: how fresh is this, where does it come from, and where are its siblings? The failures were "updated" lines written at build time that go stale, one flat colour for every age, pages with no way back to their index, and published links recorded in several places or in none. The new `devops-tools:publishing-standard` skill says what every page carries, whatever its host or styling. It also says how each published link is recorded: once, in exactly one registry that a sitemap reads but never copies. It is written to be universal: no host, account, repository or machine names.

### Summary

- **devops-tools, new skill `publishing-standard`** ([#101](https://github.com/terrylica/cc-skills/pull/101)).
  - **Every page carries:**
    - a live "changed N ago" marker with a heat dot, worked out in the reader's browser from the commit time of the page's inputs;
    - the exact moment, written at build time (a browser's time-zone database can predate a rule change);
    - the version and commit;
    - the source;
    - a link back to its site's index.
  - **One source of truth:** one `published.v1` registry per publishing repository, written by its deploy step after the URLs are verified. Links with no repository go in the sitemap's own registry. The sitemap reads them all, and the host's own inventory flags anything recorded nowhere.
  - **Audience rule:** a page links to a sitemap only when every reader who can reach it may see every link on it; otherwise it links to a sitemap built for that audience.
  - **`references/age-marker.md`:** a snippet of about 40 lines with no library or CDN. It uses `Intl.RelativeTimeFormat` with a fallback, nine OKLCH heat steps written as hex (so engines without `color-mix()` show them too), a log scale of age and a legend.
  - **`references/registry-schema.md`:** the `published.v1` fields and rules.
- **itp-hooks, new reminder `publishing-standard-reminder`.** It adds one line pointing at the skill, once per session at each of two moments: before a command that publishes pages (wrangler deploy, Orca artifact share or update, Netlify, Vercel, Firebase, surge, gh-pages), and after an HTML page is written. It never denies; the escape is `PUBLISHING-STANDARD-OK`.
- **Pointers:** `cloudflare-workers-publish`, `html-showcase:page-template`, `static-page-stack` and `full-width-artifact` each point at the standard in one line.
- **Docs fix:** itp-hooks' Bash guard count is corrected to 28; `main` already had 27 before this release, against the 26 the docs said.
