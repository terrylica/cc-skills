## Narrative

This release lets `mcp-drive.ts` drive a signed-in Chrome on another machine with no "Allow" prompt, and repairs the Playwright Extension setup for the extension's 0.6.0 release. The need came from a real session: an agent attached to a signed-in everyday Chrome on a remote Windows PC through `chrome://inspect` remote debugging, and the operator ended up clicking Chrome's "Allow remote debugging?" prompt for every connection. The Playwright Extension with a stored token never asks, but its server cannot simply run over ssh: in extension mode `@playwright/mcp` reaches Chrome by launching the Chrome binary with the extension's connect address, and a launch from an ssh session (Windows session 0, or a Linux login without the display) never reaches the user's browser. So the far side runs a small bridge inside the user's desktop session, and `mcp-drive.ts` gains a `cmd` transport that reaches it through any stdio command. While setting that up, the extension's token page turned out to have moved in 0.6.0, which broke `setup` and `rotate-token` on most profiles of the Mac too.

## Added

- **chrome-profiles, `mcp-drive.ts cmd <steps.json> -- <command...>`:** a Playwright Extension server reached through an explicit stdio command, typically `ssh <host> <bridge>`. Like `ext` it closes the run's tab; it skips the leftover sweep, which can only see this Mac's Chrome.
- **Fail fast:** a server command that cannot start, or that exits while a request is pending, now ends the run at once instead of waiting out the 180 s request timeout.
- **`mcp-drive.test.ts`** with a fake stdio MCP server fixture: round trip, tool errors, both fast failures and usage errors (5 tests). The first draft sliced the command one argument late, which these tests catch.
- **The skill** documents the transport and why the far side must serve from the user's desktop session.

## Fixed

- **Playwright Extension 0.6.0 removed `status.html`.** The token now lives on `manage.html` (window "Playwright Extension", button "Rotate token"; 0.4.x: "Playwright Extension Status", "Generate new token"), with storage unchanged. Chrome updates the extension per profile, so one machine can hold both versions. `chrome-profile.sh setup` and `rotate-token` now pick the page, window title and button from the version installed in each profile. The 0.6.0 "Rotate token" press is read from the extension's own source and has not yet been exercised by `rotate-token`.
- **Token reader messages** name the right page for each version.

## Changed

- **Doctrine:** records the 0.6.0 page move, and that a password manager's suggestion frame on Google's sign-in pages detaches an extension session (measured 2026-11-26); those few consent screens need another route.
