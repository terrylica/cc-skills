## [34.10.0](https://github.com/terrylica/cc-skills/compare/v34.9.0...v34.10.0) (2026-10-29)

Sharing a report through Orca as Markdown always produced a narrow page. Orca renders a Markdown artifact through its own template, whose stylesheet caps the body at 820 px and centres it, so on a wide screen the text sat in a column with large empty margins, and nothing in the Markdown file could change that. The share page around it was never the limit: it shows the artifact in an iframe that is 100% wide, and an HTML artifact is served exactly as uploaded. The 34.9.0 html-measure guard already checked HTML files passed to `orca artifacts share`, but it skipped Markdown, which was the case that actually produced the narrow page. This release closes that gap: the guard denies publishing Markdown to Orca, and a new orca-tools skill publishes full-width HTML instead and proves the served page is still full width after every publish.

### Summary

- **orca-tools:** new `full-width-artifact` skill. `orca-artifact-share FILE.md|FILE.html` renders Markdown with pandoc into a page with no fixed content width (wide tables get their own scroll box) or repairs uploaded HTML, lints it, publishes with `orca artifacts update` falling back to `share`, then fetches the served page through its iframe and lints that too.
- **orca-tools:** re-publishing a source keeps its link. The HTML lands at a stable per-source path, with the hash in the directory name because Orca shows the uploaded file name in the share page's header.
- **orca-tools:** `--check SHARE_URL` audits an artifact that is already published, and `--lint FILE` checks a local page. stdout is one JSON object, and Orca's CLI is found the same way as the other orca-tools scripts (never a bare `orca`).
- **itp-hooks:** the html-measure guard denies `orca artifacts share|update FILE.md` and points to the new script. `unshare`, `list`, a remote ssh path and the `HTML-MEASURE-OK` escape still pass.
- **itp-hooks:** the rule's FLAGGED/ALLOWED test vectors move to `hooks/lib/html-text-measure-vectors.ts`, with Orca's Markdown template added as a flagged case. The guard and the script's copy of the rule are both tested against them, so the two cannot drift apart.
