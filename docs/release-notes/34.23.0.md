## Narrative

This release stops outdated Gmail drafts from waiting in the Drafts folder next to the versions that replaced them. The draft builder already guaranteed one draft per thread, but a new email (not a reply) starts its own thread, so an earlier copy of it was invisible to that check. On 2026-11-21 a batch of new emails to one person was re-ranked and redrafted, and an outdated cover draft stayed beside its replacement until a manual sweep found it. Now every run of `gmail-draft.ts` reads the whole Drafts folder and names any earlier version of the new draft, and a new `gmail-drafts-audit.ts` sweeps a batch against the list of drafts still in play.

## Added

- **Lingering check on every draft:** after the new draft is verified, `gmail-draft.ts` compares it, as Gmail stored it, with every other draft. The same sender, a shared recipient and the same subject (Braille Tally cells, `Re:`/`Fwd:`, case and spacing ignored) is an earlier version: the run exits 3 naming it. Another subject to the same people is listed as `related` for a person to judge.
- **`--prune-superseded`:** deletes those earlier versions and re-lists the folder to prove they are gone.
- **`gmail-drafts-audit.ts`:** `--keep <ids>` or `--keep-file <manifest>` names the drafts in play; everything a newer draft repeats, and everything else from the same sender to the same people, is flagged; `--prune` deletes and verifies. Drafts to anyone else are never touched. Exit 0 clean, 2 could not read, 3 drafts linger.
- **JSON output:** `pruned`, `superseded`, `related` and `lingeringCheck` join the builder's one-line result; exit 4 means the draft is made but the folder could not be read.

## Fixed

- **Stored From, not requested From:** the comparison uses the draft as Gmail stored it, because Gmail rewrites a From that is not a send-as alias to the account's own address (found by the live test; the first version matched nothing).

## Changed

- **Test gate:** the builder's Layer 3 gate also runs `lingering-drafts.test.ts`, since the builder now imports that module.
- **Docs:** the gmail-access skill (§ "No earlier version may linger"), the plugin CLAUDE.md and `docs/draft-integrity-guards.md` (Layer 6) describe the rule and the sweep.
