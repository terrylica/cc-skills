## Narrative

This release makes the plugins a shared Ubuntu host runs work there as they do on a Mac, and makes Telegram links exact. Run on Ubuntu 26.04 with several people on one machine, four hooks failed on every shell command because there is no `node`, the old-git guard refused every commit because Ubuntu ships git 2.53, and fixed folders in the shared `/tmp` silently switched off a second person's type checks. At the end of every turn the Stop hook also ran `fuser -k /dev/tty`, which on Linux sends SIGKILL to every process of that user holding a terminal, editors and password prompts in other terminals included. Separately, Telegram's server stretches a bare link over any Chinese punctuation and text that follows it up to the next space, so tlg now sends every link explicitly and reads each message back.

## Fixed

- **Stop hook kills nothing outside the session (#119):** `clearTTYReferences()` and its `fuser -k /dev/tty` call are removed; a test runs the real hook with a contained `fuser` shim and proves a stand-in terminal process survives.
- **Exact Telegram links (#121):** send, draft, captions and edit turn bare links into explicit links that end where the URL ends, so a link never runs into Chinese text or full-width punctuation; every sent message is read back and the command fails naming any link that covers more than its URL.
- **`tlg relink` (#121):** repairs a message already sent, keeping its text and its mentions (an edit drops mentions unless they are sent as input mentions).
- **No `node` needed (#122):** four gh-tools hooks with a node shebang run with bun, with their tests.
- **Old git on Linux (#122):** the old-git guard refuses only when the git config defines hooks that git would skip; a deleted session directory, `git -C dir` and `cd dir && git` are judged on the right directory, and any doubt still refuses. The session warning names the OS's own fix instead of Homebrew.
- **One temp folder per user (#122):** concurrency slots, the ty marker and the hard-wrap and old-git caches carry the user id, so a second account's checks run.
- **orca-tools on Linux (#122):** spinoff and closeout find `orca-ide`; the closeout tests pass on bash 5.
- **Smaller Linux fixes (#122):** GNU-first `stat`, `sha256sum` fallback, `systemctl --user` checks, Linux clipboard tools and `xdg-open`, Linux secret-storage advice, and the macOS-only Full Disk Access helper exits 4 elsewhere.

## Added

- **Gmail OAuth client without 1Password (#122):** `GMAIL_OAUTH_CLIENT_ID` with `GMAIL_OAUTH_CLIENT_SECRET`, or `GMAIL_OAUTH_CLIENT_FILE`, never saved to disk; off macOS the consent link is printed with an `ssh -L` port-forward hint.
