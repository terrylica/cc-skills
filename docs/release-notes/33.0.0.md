## v33.0.0 — 2026-10-01

v33.0.0 is a major release because it removes four plugins: `claude-tts-companion`, `kokoro-tts`, `tts-tg-sync` and `minimax`. None of them was in use any more. MiniMax had been replaced in every consumer, and the text-to-speech that actually runs on the maintainer's Mac is a separate reader (BetterTouchTool Option+S for English, Ctrl+Option+S for Mandarin) that used none of the three TTS plugins. Three overlapping TTS stacks are now down to one. The release also closes a blind spot in the Markdown hard-wrap checks. Until now the reminder saw only Write, Edit and MultiEdit, so Markdown written through a heredoc, `python3 - <<EOF`, a generator script or `sed -i` was never checked. On 2026-10-01 a session rewrote dozens of `.md` files that way, all hard-wrapped, while the reminder stayed silent. Bash-written Markdown now gets a reminder, and `git commit`, the one boundary every authoring path crosses, gets a guard. Both share one net-new detector with the edit-time reminder. The local gate is also more trustworthy: test fixtures no longer inherit the developer's global git hooks, which had made the pre-push gate fail on load rather than on code. Two documentation corrections close long-open issues: the hook lifecycle reference now matches the official hooks doc on five disputed points, and the FXView tick-flags reference now describes all six values seen over history.

### Breaking

- **Removed plugins** (#171): `claude-tts-companion` (the Swift Telegram bot, Kokoro TTS and subtitle overlay), `kokoro-tts`, `tts-tg-sync` and `minimax`. The marketplace drops from 43 to 39 plugins. If any of them is installed, uninstall it, for example `claude plugin uninstall kokoro-tts@cc-skills`. Their sources stay recoverable from tag `v32.6.0`.
- `MINIMAX_MODEL` is no longer read anywhere. `session-debrief.ts` and `prompt-benchmark.ts` read `DEBRIEF_LLM_MODEL` and `BENCH_LLM_MODEL` instead.

### Added

- **`pretooluse-markdown-commit-hard-wrap-guard.ts`** denies a `git commit` that adds hard-wrapped prose to a `.md` or `.markdown` file. It compares what the commit records against `HEAD`, whole file, net-new only. A plain commit reads the index; `-a`/`-am` and `git commit <paths>` read the working tree. It follows `cd dir &&` and `git -C dir`, reads every blob through one `git cat-file --batch` process, and fails open outside a repository or on any git error.
- **`posttooluse-bash-markdown-hard-wrap-reminder.ts`** reminds after a Bash command that wrote wrapped Markdown. It checks two sets of files against `HEAD`: the `.md` paths the command names, and Markdown that `git status` reports dirty in the repositories it ran in and that was modified in the last 15 minutes. Each file's content is judged once per session, and the edit-time reminder shares that cache, so a wrap is never reported twice. Measured cost: 50–80 ms per Bash call warm.
- **`hooks/lib/markdown-net-new-hard-wraps.ts`**: the shared net-new layer (joiner filter, shape signature, multiset diff, escape marker, repair command, bounded git access).
- 31 tests against real throwaway git repositories, in both directions: wrapped commits denied; clean and legacy-only commits allowed; staged versus working tree; first commit; subdirectory; pathspecs; both escape forms; the dedupe cache.

### Changed

- The edit-time hard-wrap reminder imports the shared layer instead of keeping private copies. Its behaviour is unchanged, and its 44 tests pass as before.
- The `MD-HARD-WRAP` escape marker (with its `-OK` suffix) covers all three surfaces. As an HTML comment in a file it exempts that file. Anywhere in a commit command, it passes the whole commit.
- `session-debrief.ts` and `prompt-benchmark.ts` are provider-neutral (`callLLM`, `[llm]` log prefix), and the `claude-code-proxy-patterns` skill no longer names a specific provider.
- **Hook lifecycle reference** (#71, #175): five claims were checked against the [official hooks doc](https://code.claude.com/docs/en/hooks) and corrected.
  - Exit 2 on `Stop` prevents stopping.
  - Exit 2 on `PostToolUse` shows stderr to Claude.
  - `WorktreeCreate` and `WorktreeRemove` can block.
  - Prompt hooks default to the background-functionality model, not Haiku.
  - `timeout` is in seconds.
- **FXView tick flags** (#155, #176): `flags` takes six values over full history. The reference now gives the masking rule (`flags & 2 <> 0`, `flags & 4 <> 0`) and the two dated encoding transitions. It also states that bit 7 is not one of the six flags in MQL5's `MqlTick`. Literal-value filters returned no bid ticks from 2026-04-23 to 2026-08-13.

### Fixed

- **Hermetic test fixtures** (#173, #174): both suite runners export an empty `GIT_TEMPLATE_DIR`, which per git-init(1) outranks `init.templateDir`, so fixture repositories no longer run the developer's global pre-commit. Under parallel load those hooks had pushed fixture commits past bun's 5 s test budget and blocked a docs-only push.
- `scripts/install-hooks.sh` creates the hooks directory when a repository has none (any `git init --template=` repository).
- `pushover-heartbeat.sh` no longer probes the retired TTS services, which had produced a false WARN every day.

### Removed

- Four one-off hook benchmark and profile tasks, an unwired worktree-age task, the v23 migration guide and a closed 1Password rotation runbook (#170). Their findings stay in `docs/HOOKS.md`.
