## [34.7.0](https://github.com/terrylica/cc-skills/compare/v34.6.0...v34.7.0) (2026-10-26)

draft-park used to strip its provenance footer from anything meant to be sent, on the theory that a session reference was private. That theory was reversed: the session reference is now required on every outbound message, on every channel, so that any message a recipient holds can be traced back to the Claude Code session that drafted it. 34.6.0 did this for Telegram sends; this release brings draft-park in line. Text read out for sending (`get --body-only`, `--for <channel>`, `--copy`) now ends with the note's own footer line, `Parked by Claude Code | session <uuid> | <context> | <time>`, taken from the note rather than rebuilt, so it names the session that parked the draft. The safeguards that stopped the footer being pasted by hand stay: a body that carries a footer of its own is still refused, and a note with no footer is refused rather than sent without one.

### Summary

- **notes-commander:** `get --body-only`, `--for` and `--copy` append the note's footer line after the sendable body by default (`footerLineOf`, `withFooter`).
- **notes-commander:** `--no-footer` is the explicit opt-out for text that must leave without it.
- **notes-commander:** a note whose footer is missing is refused for sending, never sent bare; a body that already contains a footer is still refused.
- **notes-commander:** the footer is taken verbatim from the parked note, so the session id is the one that drafted the text, not the one reading it back.
- SKILL.md rules and evolution log updated, and the file reflowed with no hard wraps.
