## v33.1.1 — 2026-10-01

v33.1.1 continues the housekeeping started in v33.1.0, aimed at the iteration history that had piled up in places where readers expect current facts. `docs/HOOKS.md` was 80% iteration diary; it is now a 464-line reference for writing a hook today. The itp-hooks `hooks.json` descriptions, which are what `/hooks` shows, shrink from 20,258 characters to 3,342. Two of them stated wrong subhook counts, and those are corrected. 111 test files with names of 100 to 227 characters are renamed to at most 58, with every reference updated; the suites discover and run exactly the same tests. A sweep for leftover mise instructions found almost none. It did find two release tests that could no longer do their job: one asserted a preflight time that is now impossible, and one could never fail. No hook behaviour changes.

### Changed

- **`docs/HOOKS.md`** (#193, #194): 2,534 lines become 464. The Iter-76 to Iter-123 diary is removed, since git and CHANGELOG keep that history. New current-state sections cover:
  - the four in-process orchestrators;
  - the subhook contract and how to add a subhook;
  - escape-hatch markers and `tasks/marker-lookup.ts`;
  - `tasks/hook-lint/`.
- **HOOKS.md corrections** (#194):
  - The hard-block example now writes its reason to stderr and exits 2.
  - The soft-block example uses `hookSpecificOutput.permissionDecision`.
  - The output section no longer calls anthropics/claude-code#55889 and anthropics/claude-code#60993 open; both are closed.
  - The plugins-with-hooks table now includes devops-tools and rust-tools.
- **itp-hooks `hooks.json` descriptions** (#191, #192): each of the 20 is one current-state sentence naming what the hook does, its subhooks and its escape token. Only description strings changed.
- **Test file names** (#197, #198): 111 tests are renamed to `test-iterNN-<2–5 words>.sh`, at most 58 characters. Each is a git rename, so `--follow` and blame keep working. References in `moon.yml`, the release and commits scripts, the suite runners, `validate-plugins.mjs`, `RELEASE.md` and `LESSONS.md` are updated. The bun runner is now `tasks/test-marketplace-bun-unit-suite.sh`.

### Fixed

- **Subhook counts in `hooks.json`** (#192): the PreToolUse Write/Edit orchestrator runs 11 subhooks, not the 8 listed, and the PostToolUse orchestrator runs 12, not "8/15". Five tests that pinned the old wording now check the stated count against each orchestrator's registry.
- **iter-134 release test** (#195, #196): the assertion that the whole preflight finishes in under 6 s is removed; one check alone now takes about 70 s. Its shape checks stay.
- **iter-137 to iter-140 release test, check B5** (#196): it matched only the retired `mise run` form, so it could never fail. It now matches the chronicle-slicing task in any runner form.
- **Broken doc pointers** (#194, #198): three plugin docs linked to removed HOOKS.md anchors, and a hook-lint comment named a test file that did not exist.

### Known, not changed

- The PreToolUse Write/Edit orchestrator's matcher lists MultiEdit, but its code allows MultiEdit with no checks.
- That orchestrator exits 2 on ask as well as deny, so an ask blocks instead of prompting.
- `tasks/hook-lint/stop-additional-context.sh` forbids `additionalContext` on Stop hooks, which the current upstream docs accept.
