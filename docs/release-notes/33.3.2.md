## v33.3.2 — 2026-10-03

v33.3.2 fixes two bugs in the ty type-check hooks and finishes tidying the itp-hooks docs. With several Claude Code sessions open, one session's exit used to delete every other session's pending ty check and could run a check for edits it never made. Each session now checks and clears only its own gate file. The per-file ty check also stops forcing Python 3.14, so it respects a repo's own Python pin, matching the exit-time check and the rule that uv owns the interpreter. On the docs side, the escape-hatch table listed 12 tokens; it now lists all 44 the hooks honour, each checked against the code. Four thin spokes are merged into their natural homes.

### Fixed

- **ty Stop gate is per session** (#214, #215): `stop-ty-project-check.ts` reads `session_id` from its payload, runs only if `<session_id>.edited` exists, and removes only that file.
  - Before, it ran if any session had a gate file and then deleted the whole `/tmp/.claude-ty-edits/` directory.
  - If the id is missing or unsafe, the check is skipped and nothing is deleted.
  - A new `lib/ty-edit-gate.ts` is the one place gate paths are built.
- **Per-file ty check honours the repo pin** (#214, #215): it no longer passes `--python-version 3.14`. Both ty checks now take their arguments from `lib/stop-ty-project-check-args.ts`, and neither passes a version flag.
- **Escape-hatch table** (#216, #217): it goes from 12 to 44 rows, each verified at its call site for exact form and reason requirement.
  - Includes `# INIT-MONOLITH-OK` and `# gpu-optimization-bypass:`.
  - `SKILL-PLUGIN-ROOT-OK` and `RELEASE-NOTES-OK` are now marked as needing a reason of at least 10 characters.

### Changed

- **Spokes merged** (#217):
  - `biome-lint.md` and `oxlint-check.md` become `js-ts-lint.md`.
  - `memory-efficiency-reminder.md` folds into the PostToolUse orchestrator spoke.
  - `pueue-wrap-guard.md` folds into the Bash orchestrator spoke.
  - Every link is repointed.
- **Hard wraps** (#217): `gmail-body-guard.md` and `headless-claude-p.md` are unwrapped.

### Tests

- **New** `stop-ty-project-check.test.ts`: another session's gate is never touched, the hook's own gate is the only file removed, and a missing `session_id` skips the check.
- **Updated** `stop-ty-project-check-args.test.ts`: asserts the per-file argv has no `--python-version`.
